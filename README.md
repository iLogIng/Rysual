# Rysual

> Rythm Visualizer

> 音乐节奏可视化器  
> 仅支持音频流  

**依赖**
- FFmpeg
- SDL3

## 功能

- 读取多媒体文件中的音频流
- 解码音频流为 PCM 流
- 将流中的 PCM 值可视化
- 支持的操作
    - `,/.`     进度 控制
    - `-/+`     音量 控制
    - `n/p`     切换 控制
    - `s/l`     速度 控制
    - ` `       暂停 控制
